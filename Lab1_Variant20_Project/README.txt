Сборка:
1. Распаковать архив так, чтобы папки Lab1_Variant20_Project и Lab1_Variant20_Library находились рядом.
2. Открыть Lab1_Variant20_Project\Lab1Variant20.sln.
3. Собрать решение в конфигурации Debug|x64 или Release|x64.

Проект сделан как Windows Forms C++/CLI-приложение.
Основной проект вызывает функции из отдельной CLR DLL через класс ArrayLibrary::Class1.
При открытии формы создается новая случайная матрица. Кнопка «Новый пример» создает следующую матрицу.
